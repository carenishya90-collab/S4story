# Changelog

## v5.0-beta.15.1-ru.1 — 14.11.2026

Первая чистая сборка для публикации.

### Добавлено

- Русский интерфейс на основе официального релиза MC5 v5-beta.15.1.
- Русские названия в 1275 файлах пресетов.
- Дополнительные экраны рабочей сборки: архив, подробная справка по карьере, помощь при создании элементов.
- README, NOTICE, BUILD_INFO и контрольные суммы SHA256.
- Скрипты сборки и проверки релиза.

### Изменено

- `Constructor5.Base.dll`, `Constructor5.UI.dll`, `Constructor5.Elements.dll` заменены на локализованные версии.
- `Presets/**/*.Presets.xml` — переведены названия без изменения структуры.

### Удалено

- `Constructor5.Base.dll.original`, `Constructor5.UI.dll.original`, `Constructor5.Elements.dll.original`.
- `Constructor5.UI.dll.before_archive`, `Constructor5.UI.dll.before_iconpicker`, `Constructor5.UI.dll.before_softui`.
- `Presets_Backup`, `Presets_Backup_Before_Bulk.zip`, `Presets_Need_Backup_Before_Translation.zip`.
- Старый служебный README с локальными путями и пометками о резервных копиях.

### Проверено

- Запуск приложения из чистой папки.
- Открытие лаунчера и существующего проекта.
- Корректность XML всех 1275 изменённых пресетов.
- Совпадение структуры переведённых пресетов с оригиналом.
- Нет новых маркеров `???`, `TODO` и пустых названий. Два унаследованных пресета (`AllInteractionsGP07`, `AllInteractionsGP12`) содержат `???????` в названиях, как и оригинал.
- Наличие всех ключей русского XML-ресурса и 101 дополнительного ключа.
- Отсутствие служебных файлов в релизе.
- В релизе нет пользовательских проектов, модов, настроек и личных путей.

### Не проверено

- Полный экспорт модов во всех разделах.
- Работа в игре и совместимость со всеми наборами.
- Полная сборка из исходников: UI-изменения (BAML) не восстанавливались.

### Известные ограничения

- Это бета-версия; возможны ошибки экспорта.
- Часть строк может остаться на английском.
- Пресеты соответствуют данным до EP12/GP12/SP18.
- В пресетах нет описаний эффектов.
- У оригинального проекта нет файла лицензии; см. `NOTICE.md`.
