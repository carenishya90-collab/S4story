# Changelog

## v5.0-beta.15.1-ru.2 — 24.11.2026

Исправление генерации Python-скриптов при экспорте модов (`.ts4script`). Бинарные DLL не изменились.

### Исправлено

- Инъекция `InstanceManager.load_data_into_class_instances` во всех шаблонах экспорта (карьеры и супервзаимодействия, социальные миксеры, наборы лута, режиссёры зон, расширения наборов желаний, расширения перечислений): генерировалась сигнатура `def ...(original, self, packs_to_load=None)` с вызовом `original(self, packs_to_load)`. Начиная с игры 1.116.240.1020 метод вызывается только с `self`, второй аргумент давал `TypeError` и ломал загрузку тюнингов (бесконечная загрузка или вылет на выбор города). Сигнатура и вызов исправлены на `(original, self, *args, **kwargs)`.
- Инъекция `SimInfoManager.on_loading_screen_animation_finished` у триггеров действия (ActionTrigger): функция получала `original` и никогда его не вызывала, полностью подменяя метод игры (в игре это проявлялось, например, отправкой всей семьи в поездку при отправке одного сима). Теперь `original` вызывается первым, тело обёрнуто в `try/except`, результат возвращается.
- Патчер проверяет синтаксис результата перед записью; факт патча пишется в `Projects\_Tools\mc5_autopatch.log` (`PATCHED <файл> defs=… calls=… action_triggers=…`).

### Добавлено

- `tools/mc5_autopatch.py` — автопатч экспорта: хук `py_compile.compile()`, чинит оба класса ошибок до компиляции `.pyc`, поэтому исправленными оказываются и `.py`, и `.pyc` внутри `.ts4script`;
- `tools/install_mc5_autopatch.ps1` — установка хука в user site-packages Python 3.7 (работает и при GUI-экспорте, и через `ExportProject.exe` / `ExportProjectInvariant.exe`);
- `tools/patch_mc5_ts4script.py` — ручной патч уже собранного `.ts4script`;
- `tools/README_patch_mc5_ts4script.md` — документация;
- в архиве сборки скрипты поставляются в папке `Tools/`;
- `docs/RELEASE_NOTES.ru.2.md`.

### Проверено

- Тесты автопатча на реальных сгенерированных MC5 скриптах (карьера с телефонной инъекцией и черта с ActionTrigger): 12/12;
- работа исправленного скрипта в игре The Sims 4 1.129.39.1030: баг «Кто едет?» исчез, новых записей в `lastException.txt` нет;
- покрытие всех 12 Python-шаблонов MC5: остальные шаблоны (ситуации, глобальные черты, trait picker, enum-хелпер) корректны в оригинале и не требовали правок.

## v5.0-beta.15.1-ru.1 — 14.11.2026

Первая чистая сборка для публикации.

### Добавлено

- Русский интерфейс на основе официального релиза MC5 v5-beta.15.1.
- Русские названия в 1275 файлах пресетов.
- Дополнительные экраны рабочей сборки: архив, подробная справка по карьере, помощь при создании элементов.
- README, NOTICE, BUILD_INFO и контрольные суммы SHA256.
- Скрипты сборки и проверки релиза.

### Изменено

- `Constructor5.Base.dll`, `Constructor5.UI.dll`, `Constructor5.Elements.dll` заменены на локализованные версии.
- `Presets/**/*.Presets.xml` — переведены названия без изменения структуры.

### Удалено

- `Constructor5.Base.dll.original`, `Constructor5.UI.dll.original`, `Constructor5.Elements.dll.original`.
- `Constructor5.UI.dll.before_archive`, `Constructor5.UI.dll.before_iconpicker`, `Constructor5.UI.dll.before_softui`.
- `Presets_Backup`, `Presets_Backup_Before_Bulk.zip`, `Presets_Need_Backup_Before_Translation.zip`.
- Старый служебный README с локальными путями и пометками о резервных копиях.

### Проверено

- Запуск приложения из чистой папки.
- Открытие лаунчера и существующего проекта.
- Корректность XML всех 1275 изменённых пресетов.
- Совпадение структуры переведённых пресетов с оригиналом.
- Нет новых маркеров `???`, `TODO` и пустых названий. Два унаследованных пресета (`AllInteractionsGP07`, `AllInteractionsGP12`) содержат `???????` в названиях, как и оригинал.
- Наличие всех ключей русского XML-ресурса и 101 дополнительного ключа.
- Отсутствие служебных файлов в релизе.
- В релизе нет пользовательских проектов, модов, настроек и личных путей.

### Не проверено

- Полный экспорт модов во всех разделах.
- Работа в игре и совместимость со всеми наборами.
- Полная сборка из исходников: UI-изменения (BAML) не восстанавливались.

### Известные ограничения

- Это бета-версия; возможны ошибки экспорта.
- Часть строк может остаться на английском.
- Пресеты соответствуют данным до EP12/GP12/SP18.
- В пресетах нет описаний эффектов.
- У оригинального проекта нет файла лицензии; см. `NOTICE.md`.
