CHANGELOG

v5.0-beta.15.1-ru.3 — 25.11.2026
--------------------------------
Обновление автопатча экспорта до v3. Бинарные DLL не изменились.

Исправлено:
- проверка остаточных шаблонов packs_to_load выполняется по токенам
  Python: упоминания в комментариях и строках больше не мешают патчу
  (v2 пропускал файл с пояснительным комментарием packs_to_load=None,
  и скрипт оставался сломанным);
- паттерн ActionTrigger: пустая строка внутри тела функции больше не
  обрывает патч (в v2 тело обрывалось на пустой строке, результат не
  компилировался).

Проверено:
- тесты автопатча: 20/20 PASS (включая битый код с комментарием
  packs_to_load=None, ActionTrigger с пустой строкой и повторную
  компиляцию без изменений);
- симуляция экспорта DarkCoven/Shesterka с регрессией packs_to_load
  и комментарием: .py исправляется, .pyc создаётся, повторная
  компиляция идемпотентна.

v5.0-beta.15.1-ru.2 — 24.11.2026
--------------------------------
Исправление генерации Python-скриптов при экспорте модов (.ts4script).
Бинарные DLL не изменились.

Исправлено:
- инъекция load_data_into_class_instances во всех шаблонах экспорта
  (карьеры и супервзаимодействия, социальные миксеры, наборы лута,
  режиссёры зон, расширения наборов желаний, расширения перечислений):
  сигнатура (original, self, packs_to_load=None) и вызов
  original(self, packs_to_load) начиная с игры 1.116.240.1020 давали
  TypeError и ломали загрузку тюнингов; исправлены на
  (original, self, *args, **kwargs);
- инъекция SimInfoManager.on_loading_screen_animation_finished у
  триггеров действия (ActionTrigger): функция получала original и не
  вызывала его, подменяя метод игры (в игре — отправка всей семьи в
  поездку при отправке одного сима); теперь original вызывается, тело
  обёрнуто в try/except, результат возвращается;
- патчер проверяет синтаксис результата перед записью, факт патча
  пишется в Projects\_Tools\mc5_autopatch.log.

Добавлено:
- tools/mc5_autopatch.py, tools/install_mc5_autopatch.ps1,
  tools/patch_mc5_ts4script.py, tools/README_patch_mc5_ts4script.md;
- в архиве сборки скрипты поставляются в папке Tools/;
- docs/RELEASE_NOTES.ru.2.md.

Проверено:
- тесты автопатча на реальных сгенерированных MC5 скриптах: 12/12;
- работа исправленного скрипта в игре The Sims 4 1.129.39.1030:
  баг "Кто едет?" исчез, новых записей в lastException.txt нет.
