## Проверка данных

- [x] Все `Presets/**/*.xml` разбираются как XML.
- [x] Число элементов в переведённых пресетах совпадает с оригиналом.
- [x] Нет новых `???`, `TODO`, `FIXME` и пустых названий вместо непустых; два унаследованных названия содержат `???????`, как в оригинале.
- [x] Русский XML-ресурс содержит все ключи оригинала.
- [x] В релизе ровно три изменённых DLL: `Base`, `UI`, `Elements`.

Автоматическая проверка XML:

```powershell
@'
import os, xml.etree.ElementTree as ET
root = r"C:\path\to\release\Presets"
errors = []
for dp, _, fs in os.walk(root):
    for f in fs:
        if f.lower().endswith(".xml"):
            p = os.path.join(dp, f)
            try:
                ET.parse(p)
            except Exception as e:
                errors.append((p, str(e)))
print("errors:", len(errors))
for e in errors[:20]:
    print(e)
'@ | python -
```

## Проверка в игре

The Sims 4 запускается только по отдельному разрешению пользователя. Если игра запускается:

- [ ] Экспортированный `.package` найден в `Mods`.
- [ ] Мод отображается в игре.
- [ ] Нет ошибок загрузки и конфликтов с другими модами.
- [ ] Проверены хотя бы один бафф, одна черта и один простой лут.

Если игра не запускается, в описании релиза нужно честно указать: «Экспорт и работа в игре вручную не проверялись».

## Что не входит в быстрый чек-лист

- Полный перебор всех 12 категорий.
- Проверка всех дополнений и всех версий игры.
- Проверка пользовательских проектов, которые не входят в релиз.
- Проверка сторонних модов в папке `Mods`.

Эти проверки можно делать отдельными итерациями.
