## Что в этом релизе

Обновление автопатча экспорта `Tools/mc5_autopatch.py` до v3:

- **Проверка остаточных шаблонов по токенам Python**: упоминание `packs_to_load` в комментариях и строках больше не мешает патчу (v2 пропускал такие файлы, и скрипт оставался сломанным);
- **ActionTrigger с пустой строкой в теле функции**: раньше патч обрывался на пустой строке и `.pyc` не компилировался — теперь патчится корректно;
- Бинарные DLL не изменились с ru.1.

## Проверено

- Тесты автопатча: 20/20 PASS (включая «битый код + комментарий `packs_to_load=None`», `ActionTrigger` с пустой строкой и повторную компиляцию без изменений).
- Симуляция экспорта DarkCoven/Shesterka с регрессией `packs_to_load` и комментарием: `.py` исправляется, `.pyc` создаётся, повторная компиляция идемпотентна.
- `verify-release.ps1`: RELEASE CHECK PASSED.

## Установка

1. Распакуйте ZIP в отдельную папку.
2. Запустите `Constructor5.exe`.
3. Для экспорта скриптов: установите Python 3.7 (в комплекте в `Python Installer\`) и выполните `Tools\install_mc5_autopatch.ps1`.
4. Откройте или создайте проект.

## Проверка

Сверьте SHA256 скачанного архива с суммой в описании релиза и в `checksums.sha256` внутри архива.
