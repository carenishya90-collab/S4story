# The Sims 4 Mod Constructor V5 — русская сборка

Неофициальная русская локализация [The Sims 4 Mod Constructor V5](https://github.com/Zerbu/Mod-Constructor-5) от Zerbu. Сборка сделана на основе официального релиза [v5-beta.15.1](https://github.com/Zerbu/Mod-Constructor-5/releases/tag/v5-beta.15.1) (файл `Mod-Constructor-v5.0-beta.15.1.zip`) и не является официальным продуктом Zerbu или EA.

> **Важно:** в оригинальном репозитории нет файла лицензии. Эта сборка не даёт прав на распространение оригинального кода или бинарников. Подробности — в [NOTICE.md](NOTICE.md). Перед публичной выкладкой желательно получить разрешение автора оригинала.

## Статус

- Версия сборки: `v5.0-beta.15.1-ru.1`
- База: официальный релиз `v5-beta.15.1` (файл `Mod-Constructor-v5.0-beta.15.1.zip`)
- Исходный код Zerbu: коммит [`ab7df5b`](https://github.com/Zerbu/Mod-Constructor-5/commit/ab7df5b0aa89a9d2e74054653093ee33a04ab10f) от 20.08.2025
- Дата подготовки: 14–15.11.2026
- Состояние: release candidate для GitHub Releases

## Что переведено

- Основные окна и элементы интерфейса.
- Названия элементов, черт, баффов, карьер, навыков, лутов и других пресетов.
- 1275 файлов пресетов — перевод названий без изменения структуры XML.
- Дополнительные экраны, которые уже были в этой сборке: архив, подробная справка по карьере, помощь при создании элементов.

Переводы не добавляют описаний эффектов и не меняют механику игры. Названия пресетов соответствуют игровым данным, которые были в MC5 на момент базы.

## Быстрый старт

1. Распакуйте архив целиком в отдельную папку, например `%USERPROFILE%\Documents\Mod Constructor RU`.
2. Запустите `Constructor5.exe`.
3. Создайте новый мод или откройте существующий проект.
4. Для экспорта укажите папку `Mods` игры и сохраните `.package`.

Не распаковывайте сборку в `Program Files`: у приложения могут возникнуть проблемы с записью настроек и проектов. Папка `Documents` или `Desktop` подходит лучше.

Проекты по умолчанию сохраняются в:

```text
%USERPROFILE%\Documents\The Sims 4 Mod Constructor\Projects
```

В сам архив не входят проекты пользователя, моды, настройки и личные файлы. Если папка `Projects` уже существует, MC5 покажет её содержимое; на новом компьютере список проектов будет пустым.

## Требования

- Windows 10 или Windows 11 (x64).
- .NET Framework 4.8.
- The Sims 4 — только для экспорта и проверки модов в игре.
- Python не обязателен; установщик Python лежит в комплекте на случай, если он понадобится для дополнительных функций.

## Что проверено

- Приложение запускается из чистой папки.
- Открывается лаунчер и список проектов.
- Открывается существующий проект, работает основной интерфейс.
- Все 1275 изменённых XML-пресетов корректно разбираются, структура совпадает с оригиналом.
- В переводах нет новых маркеров `???`/`TODO` и пустых названий вместо непустых. Два унаследованных пресета (`AllInteractionsGP07`, `AllInteractionsGP12`) содержат `???????` в названиях — так же, как в оригинале.
- Русский XML-ресурс содержит все ключи оригинала и 101 дополнительный ключ для новых экранов.
- В релиз не попадают `.original`, `.before_*`, `Presets_Backup*` и другие служебные файлы.

The Sims 4 при подготовке сборки не запускалась. Полный прогон экспорта во всех разделах пока не автоматизирован; перед публикацией стоит вручную проверить экспорт одного простого мода.

## Ограничения

- Это бета-версия. Ошибки экспорта и несовместимости с отдельными наборами возможны.
- Часть строк может остаться на английском.
- Пресеты соответствуют данным игры до EP12/GP12/SP18; более новые обновления могут не отображаться.
- В пресетах есть только названия и ID, без описаний эффектов, длительности и условий.
- Исходники UI-изменений (BAML) не восстанавливались; текущий релиз собран из официального бинарного релиза и локализованных файлов, а не полностью из исходников.
- Сборка не проверялась на всех дополнениях и всех версиях игры.

## Сборка релиза

Нужны:

- официальный архив `Mod-Constructor-v5.0-beta.15.1.zip`;
- папка с локализованными файлами (текущая рабочая сборка);
- PowerShell 5.1 или новее;
- Python 3.7 или новее (для ZIP с прямыми слэшами).

```powershell
.\tools\build-release.ps1 `
  -BaseZip "C:\path\to\Mod-Constructor-v5.0-beta.15.1.zip" `
  -PatchRoot "C:\path\to\Mod-Constructor-v5.0-beta.15.1-RU"
```

Скрипт:

1. Распаковывает официальный релиз во временную папку.
2. Копирует только файлы из `manifest/localization-manifest.json`.
3. Проверяет SHA256 каждого изменённого файла.
4. Добавляет README, NOTICE, CHANGELOG и `BUILD_INFO.txt`.
5. Создаёт `checksums.sha256` и ZIP с именами файлов через `/` в `dist/`.

Проверка:

```powershell
.\tools\verify-release.ps1 `
  -ReleaseDir "C:\path\to\unpacked\release" `
  -ManifestPath ".\manifest\localization-manifest.json"
```

Подробная инструкция — в [docs/RELEASE.md](docs/RELEASE.md).

## Публикация на GitHub

1. Создайте репозиторий и загрузите в него файлы этого каталога (без `dist/`).
2. Создайте Release с тегом `v5.0-beta.15.1-ru.1`.
3. Прикрепите `dist/Mod-Constructor-v5.0-beta.15.1-RU.zip` как asset.
4. В описании релиза укажите базу, дату и контрольную сумму.
5. Не добавляйте ZIP в Git: для больших файлов используйте Releases.

Если репозиторий публикуется как форк, сохраните ссылку на оригинал и явно пометьте сборку как неофициальную.
